# Transport errors

Transport errors are owned by Dockline. Import shared error classes directly from @jalsoedesign/dockline-abstract; FileZilla integrations do not re-export them.

See the [current guide](https://h2ooooooo.github.io/dockline/guide/errors) and [public signatures](https://h2ooooooo.github.io/filezilla-js/reference/types).
