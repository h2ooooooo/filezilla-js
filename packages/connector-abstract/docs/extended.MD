# FileZilla factory and registry

This package exports only ConnectorFactory, ConnectorRegistry and their FileZilla registration types. Generic transfer contracts and utilities belong to Dockline.

See the [current guide](https://h2ooooooo.github.io/filezilla-js/guide/dockline) and [public signatures](https://h2ooooooo.github.io/filezilla-js/reference/types).
