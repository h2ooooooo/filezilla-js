# FileZilla TS coding conventions

Use [CODING_STYLE.md](CODING_STYLE.md). Use four-space indentation, same-line opening braces, single quotes, semicolons and compact named imports. Separate logical steps with one blank line and expand long conditions and structures for readability.

Keep formatting separate from behavior changes. Prefer explicit code, descriptive names, early validation and small functions. Run npm run lint, npm run build and relevant tests. Dependency folders and generated output are excluded from formatting.
