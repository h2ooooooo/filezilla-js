# FileZilla FTP integration

FtpConnectorFactory translates a saved FileZilla Server into a Dockline config or disconnected adapter. Generic FTP operations and errors belong to Dockline.

See the [current guide](https://h2ooooooo.github.io/filezilla-js/guide/ftp) and [public signatures](https://h2ooooooo.github.io/filezilla-js/reference/types).
